# Extend(Ed) programs page: design demo

A demo of a proposed layout for the Extend(Ed)™ program pages on caps.washu.edu, made for internal review at WashU Continuing & Professional Studies. **It is not the live CAPS website.**

- **Content:** only the programs, words and prices on caps.washu.edu, and the registration status on ce.wustl.edu, as of November 13, 2026. Nothing is added or invented.
- **Look:** the site's own header, sidebar, footer, styles, fonts and images load from caps.washu.edu. The demo adds one stylesheet and one small script for the new parts (`assets/`). No analytics or advertising tags run.
- **Links:** "Start free" buttons open the real registration site, and interest-form buttons open the real Extend(Ed) interest form.
- **Search engines:** `robots.txt` and a `noindex` tag on every page ask them not to index the demo.

Start at the hub (`index.html`). "About this demo" lists what is real, what is new, and each program's status.
